# Changelog

## 2.0.0 — Initial standalone publication

- Standalone BrowserMCP Extended extension/server repositories.
- Local WebSocket bridge on port 9877 with support for multiple MCP sessions.
- 39 MCP tools covering navigation, DOM interaction, tabs, screenshots, cookies,
  storage, JavaScript execution, file inputs, and network inspection.
- Compact control panel with persistent ON/OFF, connection settings, tab
  selection, command activity, and Lucide icons.
- Per-tab HTTP and WebSocket capture, response inspection, filters, bounded
  buffers, HAR export, and shared debugger attachment management.
- English documentation, contribution guidelines, security policy, and CI.
- Automated tests and a real Chromium fixture for network inspection.

See the README and tool reference for the current implementation limits.
